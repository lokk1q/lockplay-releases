# Каталог тем LockPlay

Плеер берёт темы отсюда: Настройки → Темы → «Каталог тем».

Хочешь свою тему в каталог? Сделай её в плеере (Настройки → Темы → «Сохранить текущую как тему» → «Экспортировать…»)
и кинь файл в [Telegram-канал](https://t.me/lockplay_off) или в [Issues](https://github.com/lokk1q/lockplay-releases/issues).
